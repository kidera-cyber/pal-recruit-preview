# 画像の差し替えについて

## person-corporate.jpg（コーポレートのカード／インタビューHERO）

現在は `office.jpg`（オフィス全景）から、打ち合わせ中のメンバーに寄せてトリミングした
暫定画像です。**人物の顔がはっきり見える写真ではありません。**

他3カード（FDE／システム部／営業）と同じ「人物が主役」の見え方に揃えるには、
以下の条件の写真を用意し、**このファイルを同名で置き換えてください。コードの変更は不要です。**

| 項目 | 指定 |
|---|---|
| ファイル名 | `assets/person-corporate.jpg` |
| 推奨サイズ | 1600 × 1200 px（4:3）／ JPEG・300KB前後 |
| 構図 | 人物の上半身〜全身が主役。背景にデスク・PC・資料・社内空間 |
| 内容 | コーポレート部門で働く社員。採用・人事・管理・経営管理が連想できる要素 |
| トーン | 明るく落ち着いたオフィス。自然で知的な印象。BtoB企業らしい清潔感 |
| 避ける | 会議室だけの風景／人物が小さい／宣材写真的なポーズ／受付・秘書に寄った表現 |

### 画像生成を外部ツールで行う場合のプロンプト

> 日本の物流DX企業のコーポレート部門で働く社員。明るく落ち着いたオフィスで、PCや資料を
> 使いながら組織運営や人事・管理業務に関わっている様子。知的で信頼感のある表情。人物が主役。
> 採用サイト向けの自然でリアルなビジュアル。BtoB企業らしい清潔感と人間味。4:3の構図。
