## 1. 添付バナーから抽出したデザイン特徴

参照したのは Downloads にあった物流DXコラムバナー5点（いずれも 2172×724）。
うちPALブランドのものは「CLO義務化を競争力に変える物流DX」「現場と技術をつなぐFDEサイトリニューアル」など。

### 実測した色の構成

| 色 | 面積比 | 役割 |
|---|---|---|
| **白 `#FFFFFF` / `#FEFEFE`** | **約25〜28%** | 主役の背景。情報を整理する余白 |
| **黒 `#000000`** | 約1% | 大見出し・ラベル帯。面積は小さいが視覚の中心 |
| **赤 `#CF131B` / `#F61C25` / `#C20104`** | 細い面 | 斜めのライン、キーワード、CTA |

### ① 赤・黒・白の強いコントラスト
**黒背景が主体のデザインではありません。** 白が面積の1/4を占め、黒は見出しとラベル帯に、赤は斜線とキーワードに絞られています。

### ② 大胆なタイポグラフィ
日本語の見出しが最大要素。英字ラベルは小さく、黒地に白文字の帯（「物流DXコラム」「SITE RENEWAL」）として添えられています。

### ③ 斜めの構図
**右側**に赤い斜めストライプが入り、写真も斜めに切られています。全面ではなく、**画面の片側だけ**です。

### ④ 写真とメッセージの関係
左にメッセージ、右に写真・画面キャプチャ。写真は主張の裏づけとして置かれています。

### ⑤ 情報のメリハリ
見出しは極大、補足は小さく1〜2行。中間のサイズがほとんどありません。

## 4. A案とB案の比較

**色は完全に同一です。** 違うのはレイアウト・タイポグラフィ・写真の扱いだけです。

| | **A案 PAL CORPORATE STYLE** | **B案 PAL RECRUIT EDITORIAL** |
|---|---|---|
| コンセプト | バナーの表現をそのまま持ち込む | 同じ色で、採用サイトらしい編集的な見せ方 |
| HERO | **動画を全面に敷き、黒のオーバーレイ**。白の大見出し＋明るい赤の「自分の手で、」 | **白のメッセージパネルを動画に重ねる**。黒の大見出し＋赤の「自分の手で、」。バナーの「左にメッセージ／右に写真」に近い |
| セクションラベル | **黒地に白文字の帯**（バナーの「物流DXコラム」と同形） | 赤の縦バー＋黒文字 |
| 見出しの下 | 赤のルール 64×4px | 赤72px＋グレーの全幅ライン |
| 斜めの構図 | **グレー面の右上に赤い斜線**（不透明度10%・2箇所のみ） | 使わない（余白で見せる） |
| 社員カード | 現行サイズ | **アバター 78→82px、カードを大きく** |
| 余白 | 現行 | **セクション上下を 66〜112px に拡大** |
| JOIN PAL | **黒ベタ**＋上辺に赤のグラデーションライン | **赤ベタ**＋黒のCTA |
| ページ高さ（1280px） | 現行とほぼ同じ | やや長い（余白拡大のため） |
| ページ高さ（390px） | 8,505px | 8,800px |

### 評価

**PALの採用ブランドとしては B案を推します。**

- A案はバナーに忠実で、コーポレートサイトとの統一感はいちばん強い。ただし動画全面＋黒オーバーレイは、現行のネイビー版と構図が同じで「色が変わっただけ」に見えやすい
- B案の白パネル×動画は、バナーの「左にメッセージ／右にビジュアル」という構図をWebに翻訳したもので、**バナーの設計思想により近い**。黒の見出しが白地に乗るため可読性も最も高く、採用サイトらしい親しみやすさも保てる
- ただし「コーポレートサイトとの統一感」を最優先するならA案

## 6. CSSの変更範囲

`assets/style.css` に `PALBRAND v1` を**追記のみ**（削除0）。
すべて `.dr-a` / `.dr-b` 配下で、正式サイトはどちらのクラスも持たないため表示は変わりません。

既存の `--navy` `--text` `--sub` `--line` `--bg-soft` などのトークンを
**テーマのスコープ内で再定義**しているため、個別セレクタへの色の直書きはほぼ不要でした。
本展開時は、これらを `:root` に畳み込む形にします（上書きの積み増しにはしません）。

## 8. 全ページ展開時の注意事項

1. **A案／B案のどちらを基準にするか**
2. 展開順は HOME → WORK → PEOPLE → CAREER → JOBS → FAQ → ENTRY → 社員インタビュー・職種詳細
3. `--navy` を黒へ置き換えると、`.sec--navy`（PEOPLE の OUR VALUES）・`.chap--msg`（インタビューのMESSAGE）・`.phil`（CAREER）など**濃紺面を持つ既存コンポーネントがすべて黒になります**。意図どおりか要確認

### 9-2. 既定化にあたって直した「濃紺の残骸」

承認時に §8 で注意点として挙げた「`--navy` を黒にすると濃紺面がすべて黒になる」は、
**どの補助色もコントラストが上がる**ことを先に確認してから実施した（黒のほうが背景が暗いため）。

さらに、トークンを通らず**直書きで残っていた青みのある色 214 箇所**を、
元の相対輝度に一致するニュートラルグレーへ置換した。輝度を合わせているので、
コントラスト比は一切悪化していない。

- CSS 201 箇所（`#c3cade`×72／`rgba(38,41,70)`×18／`rgba(27,29,49)`×18 ほか36種）
- HTML のインライン指定 80 箇所（フッターの社名・リンク色など）
- 暗色オーバーレイと影の `rgba(27,29,49,…)` `rgba(38,41,70,…)` 計36箇所は純黒へ
- 旧 `--pink:#f72a48`（赤紫）→ `#f61c25`、旧 `--red-light:#ffb3b8`（淡いピンク）→ `#f61c25`
- 旧 `--grad`（紫→ピンク）→ 赤のグラデーション。白文字を乗せる面だけは
  `--grad-fill`（止めを `#cf131b` に）を別に用意した。`#f61c25` は白文字 4.11:1 でAA未達のため
- 4色凡例 `.pftl`（紫を含んでいた）→ 黒・赤・グレー・明赤の4段階

### 9-3. 実装中に見つけて直した不具合（いずれも既定化で初めて露見）

1. **`.sec--navy p`（特異度 0,2,0）が `.slabel`（0,1,0）に勝ち**、黒地の白ピルの中の文字が
   白のまま残って不可視（1.07:1）だった → `.slabel.slabel` で特異度を揃えて後出しで解決
2. **中央寄せの見出しで、赤ラインだけ左に残っていた** → `margin-inline:auto`
3. **ドロワー内の赤いENTRYボタンの矢印**が `.drawer a span{color:var(--muted)}` を拾い、
   赤地にグレーの矢印（1.05:1）だった → `:not(.btn__ico)` で除外
4. **黒地の「LOGITECH INTEGRATION」「MESSAGE」** が `#cf131b`（黒地 3.76:1）のまま
   → `--red-on-dark` へ
5. WORKページのラベル下にあった赤い短い棒は、新しい見出し下の赤ラインと役割が重複するため
   未使用化（残置コメント）

### 9-4. 検証結果

対象20ページ × 1280px / 390px ＝ **40レンダリング**を機械検査。

- WCAG AA コントラスト違反：**0件**（擬似要素 `::before` `::after` も含む）
- 横スクロールの発生：**0件**
- 描画される有彩色：`#CF131B` と `#F61C25` の**2色のみ**。
  それ以外はすべて無彩色（黒・白・グレー）

> 検査から除外したのは、動画・写真の上に白文字を置いている箇所
> （`.hero` `.entry` `.pcard__copy` `.role__phcta` ほか）のみ。
> 背景色を持たないため祖先を遡ると誤判定になるため。
