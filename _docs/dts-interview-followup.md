## 3. ★ 追加できなかった理由と、追加取材が必要な項目

アンケートの回答は全12問で**実質約600字**です。前回の改稿（IV-DTS v1）の時点で
46項目を機械照合し、**未使用の記述は残っていません**。
そのため、事実を増やすには追加取材が必要です。

一度は書いたものの、**根拠が辿れないため削除した文**：

| 削除した文 | 削除理由 |
|---|---|
| 「新しい運行が1本増えるということは、どの車両を、どのドライバーが、どの時間に動かすかを組み直すということです」 | 配車の具体的な手順。本人は「配車に組み込み」としか回答していない |
| 「数字や手順で決めきれない部分が残ります」「一度伝えて終わりにはできません」 | 安全管理の難しさの言い換えだが、本人の表現にない |
| 「運行時間、待機時間、日報、勤怠、位置情報。配車を組むのも…こうした日々の情報を見ながらです」 | データの使途。本人は「見ている」としか回答していない |
| 「扱える車両が増えれば、受けられる仕事も変わります」 | 本人の回答にない解釈 |
| 「ドライバーに走ってもらって、その結果が売上になる」 | 新規営業と売上の因果。本人の回答にない |

### 追加取材で聞けると、記事の具体性が上がる項目

1. **配車・配送計画の進め方**（1日のどのタイミングで、何を見て決めるのか）
2. **運行時間・待機時間・位置情報を、具体的に何の判断に使っているか**
3. **安全管理で実際にしていること**（教育・意識づけの具体的な場面。制度名ではなく本人の行動）
4. **千葉営業所の規模感**（車両台数・ドライバー人数など、公開可能な範囲で）
5. **4t→10t→所長のそれぞれで、何が一番変わったか**
6. **印象に残っている出来事**（Q7の「バッチリ決まった時」の、差し支えない範囲の具体例）
7. **扱っている荷物・配送先の種類**（保冷車両を使っていることは Q9 から分かるが、荷種は未確認）
8. **DTSシステムの名称と、本人が触れている機能の範囲**

これらが取れれば、目標の 20〜35% 拡充は無理なく達成できます。
