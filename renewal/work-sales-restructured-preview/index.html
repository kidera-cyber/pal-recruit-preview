Why this work matters

OPERATION

BPO / 現場運営

現場を安定させ、改善を進める

主な仕事

  • 各拠点の稼働状況の確認と、人員配置
  • 作業進捗・品質・安全の管理
  • 生産性・収支の確認と、業務改善の推進
  • 取引先との打ち合わせ、現場確認
  • 拠点間の調整と、改善施策の横展開

この仕事らしさ

現場を安定して回しながら、より良い運営へ改善していくこと。改善が、そのまま現場の変化になります。

関わる相手

  • 現場スタッフ
  • 拠点責任者
  • 取引先
  • DX・システム部門

現場を止めずに、やり方を変えていく。

物流センターの運営を預かる仕事です。日々の稼働を安定させながら、人員配置・作業進捗・品質・安全・生産性・収支を見て、現場の改善まで担当します。拠点によって顧客の業態、取り扱う商品、勤務シフトが異なります。

仕事の進め方

  1. 01現場の状況を把握する

    稼働を見る各拠点の稼働状況を確認し、その日の作業量をつかむ。

  2. 02人員と作業を組む

    人員を配置する作業量に合わせて人員を配置する。

    進捗を見る作業の進み方を管理し、滞りがあれば手を打つ。

  3. 03数値で確かめる

    品質と安全作業品質と安全を保つための確認を行う。

    生産性と収支生産性・売上・原価を確認し、課題の優先順位を決める。

  4. 04改善につなげる

    やり方を変える作業方法の見直しや機械化を進める。

    取引先と話す取引先との打ち合わせや現場確認を重ね、改善提案につなげる。

※ 仕事を理解するための整理で、全員が同じ順序・同じ責任範囲で担当するわけではありません。担当する業務は拠点と募集レベルによって異なります。新しく受託する拠点では、立ち上げから関わることもあります。

この仕事で大切にしていること

  • 01人を増やす前に、作業そのものを疑う

    課題に対して人を増やすだけで解決するのではなく、作業そのものを変えられないか、機械やシステムに置き換えられないかを考えます。

  • 02現場のメンバーの意見から始める

    現場で働くメンバーの意見を大切にしながら、既存のやり方にとらわれない改善を考えます。

  • 03数字と現場の両方から判断する

    生産性や収支の数字と、現場で実際に起きていることの両方を見て決めます。

  • 04顧客と条件を話す（責任者候補の役割）

    拠点によっては、クライアントとの物量・単価・オペレーションの交渉を通じて、拠点の収益改善を担当します。

CLEANLINESS

Cleanliness / クレンリネス

清掃を、計画と運用で支える

主な仕事

  • 食品プロセスセンターなどの日常清掃・特別清掃
  • 汚れ方と頻度から考える清掃計画づくり
  • 各現場の巡回と、清掃状態の確認
  • 複数センターの進捗・作業終了報告の管理
  • 見積・請求の作成と、協力会社との連絡

この仕事らしさ

清掃を実施するだけでなく、計画を考え、複数の現場の運営まで含めて支えること。

関わる相手

  • 各センターの現場
  • 協力会社
  • 取引先

清掃をして終わり、ではない。

食品プロセスセンターなどの現場で、日常清掃と特別清掃を行います。汚れの状態と頻度を確認して清掃計画を立て、現場との連携まで担当します。

仕事の進め方

  1. 01現場で清掃する

    日常清掃・特別清掃食品プロセスセンターなどの現場で清掃を行う。

  2. 02汚れ方から計画を立てる

    清掃計画をつくる汚れの状態と頻度を確認し、どこをどの頻度で清掃するかを考える。

  3. 03現場を回って確かめる

    巡回する各現場を巡回し、清掃状態を確認する。

    報告を管理する複数センターの進捗と作業終了報告を管理する。

※ 担当する現場と業務の範囲は人によって異なります。全員が複数拠点の管理や清掃計画の策定を担当するわけではありません。見積・請求の作成や協力会社との連絡、クレンリネス課の運営、清掃案件の営業に関わる場合もあります。

この仕事で大切にしていること

  • 01困りごとを早くつかむ

    各センターの困りごとをいち早くキャッチし、改善につなげて信頼関係を築きます。

  • 02安全衛生は当然のこととして

    安全衛生を前提としたうえで、現場の状態に常にアンテナを張ります。

※ クレンリネスは現在募集していません。仕事内容の紹介として掲載しています。

FORWARD DEPLOYED ENGINEER

FDE

現場課題を技術へつなぐ

主な仕事

  • 物流現場での業務課題のヒアリングと整理
  • 課題を技術要件へ翻訳する
  • システム・設備・データとの接続を設計する
  • 開発・改修と、現場での動作確認
  • 運用後の問い合わせ対応と改善

この仕事らしさ

現場の課題を技術要件へ整理し、実際に動く仕組みまで持っていくこと。つくった仕組みが、現場に定着します。

関わる相手

  • 物流現場のスタッフ
  • BPO / 現場運営
  • システム / プロダクト企画

仕様書だけでは、現場は動かない。だから、現場に入り込む。

FDE（Forward Deployed Engineer）は、顧客の業務課題と技術の間をつなぐエンジニアの職種です。立ち位置は、顧客に近い場所。課題を整理して提案するだけでなく、技術を実際に使える形へ落とし込むところまで関わります。生み出すものは提案書や計画ではなく、現場で使われる仕組みです。

仕事の流れ

  1. 01現場を知る

    現場へ行く倉庫や配送の現場に入り、実際の動きを見る。

    話を聞く現場責任者や作業者に、何に困っているかを聞く。

  2. 02課題を技術へつなぐ

    課題を整理する帳票外の判断や例外処理を書き出し、論点を絞る。

    技術要件へ翻訳する現場の言葉を、画面・帳票・データの要件に置き換える。

  3. 03仕組みをつくる

    設計する平常時の運用と、止まったときの切り替えを設計する。

    実装するエンジニアと組み、自社プロダクトを現場に合わせて形にする。

  4. 04使われ方を見て改善する

    使われ方を見る導入後に現場へ戻り、実際に使われているかを確認する。

    改善する訓練を重ね、手順とシステムを更新し続ける。

※ 上の4つは仕事内容を理解するための整理で、すべての案件が同じ順に進むわけではありません。進め方はプロジェクトや現場によって異なります。設計・実装・運用は、システム / プロダクト企画やBPO・現場運営などの専門部門と分担して進めます。

FDEが大切にしていること

  • 01例外処理を、業務観察から拾い上げる

    仕様書に現れない現場の判断を可視化する。

  • 02暗黙知を、代替運用の設計へ

    属人化していた手順を、ほかの人でも動かせる形にする。

  • 03効率化と、止まったときの切り替えを設計する

    平常時の運用だけでなく、止まったときの手順まで含めて考える。

  • 04訓練を通じて、手順を更新し続ける

    設計して終わりにせず、現場に伴走しながら手順を直していく。

SYSTEM / PRODUCT

System / Product

現場で使われる仕組みをつくる

主な仕事

  • 現場ヒアリングと要件整理
  • 物流センター向けAndroidアプリの設計・開発
  • OCR・バーコード読み取り、ダッシュボードの開発
  • 倉庫での実機確認と、改善対応
  • 現場フィードバックの反映と、活用推進

この仕事らしさ

つくって引き渡すのではなく、現場で使われる状態まで関わること。見えなかったデータが、判断を変えます。

関わる相手

  • 物流現場
  • FDE
  • プロダクト企画

つくったものが、どう使われるかを見に行く。

物流センターの現場で使われるプロダクトを、自社で企画・開発します。仕分け作業で使うAndroidアプリ、バーコードの読取、カンバンのOCR読取、出荷日ごとの採番、仕分け状況のダッシュボードなどを、現場の課題に合わせてつくり、リリース後も改善を続けます。

仕事の進め方

  1. 01現場の要望を聞く

    ヒアリングする現場の要望を聞き、要件を整理する。

  2. 02設計・開発する

    機能をつくるAndroidアプリ、読み取り機能、ダッシュボードなどを設計・開発する。

  3. 03倉庫で確かめる

    実機で確認する倉庫で実際に動かして確認し、改善に対応する。

  4. 04リリース後も直し続ける

    反映する現場からのフィードバックを機能追加や改善として反映する。

    使われる状態にする活用推進まで関わる。

※ 現場との関わり方は、担当する案件によって異なります。

この仕事で大切にしていること

  • 01止められない現場に出すということ

    現場の作業は止められない一方で、改善のスピードも同時に求められます。不具合が出たときの切り戻しや修正方法を事前に用意したうえでリリースします。

  • 02使う人の顔が見える距離でつくる

    つくって引き渡すのではなく、現場で使われる状態まで関わります。

  • 03FDEとの役割の違い

    FDEは現場の課題を技術要件へ整理し、各部門と連携して実装・改善につなぐ役割です。System / Product は自社プロダクトそのものの企画・開発を担当します。同じ案件で連携します。

TRANSPORT

DTS / 運送・運行

安全・品質・時間を守って届ける

主な仕事

  • 配送業務・納品対応
  • 車両点検と、運行前後の確認
  • 安全運転・配送品質の維持
  • 配車と運行状況の確認・調整
  • 配送先・物流センターとの連携

この仕事らしさ

届けるだけでなく、安全・品質・時間を同時に守ること。組み直した計画が、そのとおり回ります。

関わる相手

  • 配送先
  • 物流センター
  • ドライバー

運ぶ人と、運行を組む人。

DTS事業部・運送課には、実際に配送を担当するドライバーの仕事と、配車・運行を組む営業所の仕事があります。現在募集しているのは、千葉県船橋市のafs船橋センターを拠点とする4tルート配送ドライバーです。

配送ドライバーの仕事の流れ

  1. 01出勤・出発準備

    点検する営業所に出勤し、アルコールチェックと車両の点検を行う。

  2. 02積み込み・確認

    確認する用意されたカゴ車と、専用端末で配送先を確認する。

    積み込むカゴ車をトラックに積み込み、配送先へ出発する。

  3. 03店舗へ配送

    降ろす店舗に到着し、パワーゲートを使ってカゴ車を降ろす。

  4. 04回収・帰庫

    回収する納品後、サンテナやカゴ車を回収する。

    戻るすべてのルートを回り終えたら営業所に戻り、片付けて退勤する。

※ 上は現在募集中の4tルート配送ドライバーの仕事です。営業所の管理の仕事（顧客とのやり取り、配車・配送計画、売上管理、ドライバー管理、新規営業）は、社員インタビューで紹介している役割で、この募集の仕事内容とは異なります。

この仕事で大切にしていること

  • 01安全・品質・時間を同時に守る

    届けるだけでなく、安全運転と配送品質、時間の3つを同時に守ります。

  • 02その日の配送が成立する組み方を決める（営業所の管理の役割）

    どの車両をどう動かせば、その日の顧客の配送が成立するのか。営業所では、そこを決めることが仕事になります。

  • 03まずやってみて、相談する（営業所の管理の役割）

    運行については、まずやってみる。そのうえで、本部長やほかの管理者に相談する。

Engagement / Sales・BizDev

営業・事業開発｜顧客課題を次の提案につなげる

要望の裏にある、本当の課題を探す。

顧客との接点をつくり、現場を見て課題を整理し、社内の専門部門へつなぐ仕事です。あわせて、顧客課題や市場機会をもとに新しい事業・サービスの可能性を検討する事業開発（BizDev）も、同じ枠組みのなかにあります。営業と事業開発は、それぞれの役割を持ちながら連携します。

営業と事業開発、それぞれの役割

  1. SALESEngagement / Sales

    担うこと顧客との関係づくりと課題の把握、提案機会の創出を担当する。

  2. BIZDEVBizDev

    担うこと顧客課題や市場機会をもとに、新しい事業・サービスの可能性を検討し、形にする。

仕事の進め方

  1. 01接点をつくる

  2. 02現場を見て、課題を聞く

    見学する現場見学をしながら課題をヒアリングする。

  3. 03提案できる範囲を見極める

    特定するPALが提案できる範疇を特定する。

    整理する課題に必要なデータを分析し、初回提案の方向性を整理する。

  4. 04社内へつなぐ

    トスアップする設計部門や社内の提案専門組織へつなぐ。

    還元する顧客の反応をマーケティング部門へ戻し、施策の精度を高める。

提案から現場導入までは、FDE・BPO・システム / プロダクト・DTSと分担して進めます。

この仕事で大切にしていること

  • 01すぐ受注にならなくても、関係を続ける

    長期的な視点でお客様との関係構築を続ける工夫を大切にしています。

  • 02現場と経営の両方の視点で見る

    現場の課題だけでなく、経営的な視点での課題も深く理解します。

  • 03一次情報を社内へ戻す

    現場で得た顧客の反応をマーケティング部門へ還元し、施策の精度を高めます。

STAFFING SALES

人材派遣営業

人材の提案から、物流現場の改善につなげる

主な仕事

  • 求人を出している企業へのアプローチ
  • 既存顧客からの他拠点紹介
  • 欠員や業務ボトルネックのヒアリング
  • 物流倉庫への人材派遣の提案
  • 自社開発の勤怠管理システム・作業可視化システムの導入提案

この仕事らしさ

物流現場の人員課題に向き合いながら、勤怠管理や作業可視化の仕組みを活用し、自動化・省人化につながる提案にも関われること。

関わる相手

  • 物流倉庫の顧客企業
  • 既存顧客
  • 営業事務

人材の提案だけで、終わらない。

物流倉庫への人材派遣の法人営業です。労働力の提供にとどまらず、顧客の課題に応じて、社内の専門部署と連携しながらシステムの活用や省人化につながる提案までを行います。求職者対応は営業事務4名が担当しているため、営業は企業への提案に時間を使えます。

仕事の進め方

  1. 01顧客との接点をつくる

    案件を獲得する求人を出している企業へアプローチする。

    広げる既存顧客から、ほかの拠点を紹介してもらう。

  2. 02現場の課題を聞く

    欠員を確認する人員の欠員状況を確認する。

    詰まりを探す業務上のボトルネックをヒアリングする。

  3. 03人材・仕組みを提案する

    人材を提案する顧客の人員課題に応じた人材派遣を提案する。

    仕組みを提案する課題に応じて、社内の専門部署と連携しながら、自社開発の勤怠管理や作業可視化のシステムを提案する。

  4. 04営業活動を管理・改善する

    逆算する目標から逆算した行動計画を立てる。

    見直す営業行動の量と質を高め、プロセス管理を自ら実践する。

4段階は仕事の流れを理解しやすくするための整理で、すべての案件がこの順に進むわけではありません。

この仕事で大切にしていること

  • 01人の課題を入口に、現場の課題を見る

    欠員だけでなく、どこに時間がかかっているのかまで聞きにいきます。

  • 02自社のシステムを提案に使う

    作業可視化システムなどで現場の状況をデータにし、社内の専門部署とともに自動化・省人化につながる提案へつなげます。

  • 03目標から逆算して動く

    組織の営業行動量と質を高め、目標達成に向けたプロセス管理を自ら実践します。

  • 04店舗運営・労務管理の経験が活きる

    店長・副店長などで労務管理を経験した方が、その経験を活かして働いています。

CORPORATE

Corporate

組織と働く環境を支える

主な仕事

  • 社宅・社用車・通信・資産管理などの日常業務
  • 社内申請のシステム化
  • 業務フロー改善
  • 関係部署との打ち合わせと、中長期的な課題への対応

この仕事らしさ

日常業務を支えながら、社内の仕組み自体も改善していくこと。

関わる相手

  • 各部署のメンバー
  • 社員

社員が働くための業務と、会社運営の業務。

コーポレート本部には、社員が日々働くために必要な業務と、会社運営に関わる業務の両方があります。ここで紹介しているのは総務課の仕事です。

仕事の進め方

  1. 01日常業務を管理する

    進捗を見る社宅・社用車・通信・各種保険・事故対応・資産管理などの進捗を管理する。

  2. 02会社運営の業務を進める

    手続きを担う会社の登記関連業務や、プライバシーマークの維持などを担当する。

  3. 03仕組みを改善する

    直す社内申請のシステム化や、業務フローの見直しに取り組む。

※ 掲載しているのは総務課の業務です。人事・経理・法務など、ほかの部署の業務分担は確認中です。コーポレートの担当者全員が、これらをすべて担当するわけではありません。

この仕事で大切にしていること

  • 01離れた場所の人に、早く返す

    リモート勤務や各拠点の現場担当者との連絡は基本的にチャットが中心となるため、できるだけ迅速に回答することを心がけています。

  • 02正確に進めたうえで、仕組みをつくる

    日常業務を正確に進めるだけでなく、会社全体の生産性向上につながる仕組みづくりにも取り組みます。
