## 1. 結論：現在のFVビジュアルは **すべて仮素材** です

PAL社員の実写であることを確認できた写真はありません。本実装に進む前に、
**掲載許諾のある社員写真・現場写真への差し替え**が必要です。

根拠：`docs/interview-question-sheet.md` に、写真の扱いが
「イメージ写真／既存写真のトリミング → 本人撮影に差し替え」と記載されています。
また `assets/person-*.jpg` は 2026-09-18 の初回一括登録（commit `272afa5`）で入ったもので、
撮影者・被写体・許諾の記録が残っていません。

## 4. 差し替え時のチェックリスト

- [ ] 被写体本人から掲載許諾を得ているか（社員写真の場合）
- [ ] 顧客現場が映る場合、顧客側の掲載許諾を得ているか
- [ ] 荷主名・取引先名・個人名が写り込んでいないか（社員証・ラベル・サイネージ）
- [ ] 横位置 1600×1200 以上、容量 400KB 以下（FVメインは `fetchpriority="high"`）
- [ ] `alt` を実態に合わせて書き換える（現在の `alt` は仮素材の内容に対する記述）
- [ ] スマートフォン幅（390px）で顔が切れないか。切れる場合は CSS の
      `.rhero__ph--main img{object-position:…}` を調整する

# 追記（2026-10-19）｜ファーストビュー動画について

## 1. 配置したファイル

| ファイル | 内容 |
|---|---|
| `assets/video/hero-pal-2026-10.mp4` | 受領した `gemini_generated_video_07a5f44c.mp4` を**無劣化のままコピー**（SHA-256 一致を確認）。1280×720 / 10.01秒 / H.264(avc1) / 4.37MB |
| `assets/video/hero-poster.jpg` | 上記の 0 秒地点から生成したポスター画像。1280×720 / 128KB |

**既存の動画はありません。** サイト全体を `<video` で検索した結果 0 件で、
現在のTOPのファーストビューは静止画 `assets/warehouse-dx.jpg` です。
したがって今回は「差し替え」ではなく**新規導入**であり、バックアップすべき旧動画は存在しません。

再エンコード（圧縮）は行っていません。ffmpeg がこの環境になく、かつ
「動画の内容・色調・尺・アスペクト比を無断で変更しない」という指示があるためです。
`preload="metadata"` とポスター画像で初期表示の負荷を抑えています。
音声トラック（mp4a）が含まれたままですが、`muted` 再生のため音は出ません。
容量を削りたい場合は、音声トラックの除去と Web 向け再エンコードで 2MB 前後まで下げられます（要ご指示）。

## 2. ※要確認：この動画は PAL の実際の現場ではありません

映像の内容（0／3／6／7.5／9秒を目視確認）：

- 多数のAGV・AMRが走行する完全自動化倉庫
- GTP（Goods to Person）ステーション、ロボットアーム、自動搬送コンベヤ
- タブレットを操作する人物が1名（CG／AI生成）
- 俯瞰でのフルオートメーション・ソーティングライン

ここから2点、ご確認をお願いします。

1. **実在しない現場・人物です。** 今回のプロンプトの「存在しないPAL社員や現場」「不自然なAI生成人物」
   を使わないという条件、および「フィジカルAIについて、未確認の導入実績や業務内容を追加しない」
   という条件に抵触する可能性があります。
2. **映像の自動化レベルが、PALの現場として確認できていません。** 無注記で採用サイトの
   ファーストビューに置くと、「PALの物流センターはこうなっている」と読まれます。

### 緩和策の案（いずれも未適用・ご指示があれば実装します）

- 画面内に小さく「イメージ映像」と表示する
- 人物が映るカット（約5〜7秒）を避け、設備のみのカットでループさせる
- 実際のPAL現場の撮影素材に差し替える

## 3. 再生設定（実測）

`autoplay muted loop playsinline preload="metadata"` ＋ `poster`。
1280px・390px の両方で自動再生・インライン再生・ループを実測確認済み
（`paused=false`／1秒で `currentTime` が 0.9〜1.0 秒進行）。
`prefers-reduced-motion: reduce` では CSS で動画を非表示にし、ポスター画像のみを表示します。
