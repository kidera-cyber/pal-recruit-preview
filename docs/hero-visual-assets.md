# TOP ファーストビュー｜使用ビジュアルの出自メモ

作成日：2026-10-19（HERO-RB v1）
対象：`renewal/hero-a.html`（案A）／`renewal/hero-b.html`（案B）＝ 比較用プレビュー

---

## 1. 結論：現在のFVビジュアルは **すべて仮素材** です

PAL社員の実写であることを確認できた写真はありません。本実装に進む前に、
**掲載許諾のある社員写真・現場写真への差し替え**が必要です。

根拠：`docs/interview-question-sheet.md` に、写真の扱いが
「イメージ写真／既存写真のトリミング → 本人撮影に差し替え」と記載されています。
また `assets/person-*.jpg` は 2026-09-18 の初回一括登録（commit `272afa5`）で入ったもので、
撮影者・被写体・許諾の記録が残っていません。

## 4. 差し替え時のチェックリスト

- [ ] 被写体本人から掲載許諾を得ているか（社員写真の場合）
- [ ] 顧客現場が映る場合、顧客側の掲載許諾を得ているか
- [ ] 荷主名・取引先名・個人名が写り込んでいないか（社員証・ラベル・サイネージ）
- [ ] 横位置 1600×1200 以上、容量 400KB 以下（FVメインは `fetchpriority="high"`）
- [ ] `alt` を実態に合わせて書き換える（現在の `alt` は仮素材の内容に対する記述）
- [ ] スマートフォン幅（390px）で顔が切れないか。切れる場合は CSS の
      `.rhero__ph--main img{object-position:…}` を調整する
