## 2. 掲載先の提案（※実施していません）

### 案A：ABOUT の冒頭へ ← 推奨

ABOUT は「PALはどのような企業か」を担うページで、現在 `#why`（なぜ今、物流の仕組みを見直す必要があるのか）から始まります。
その手前に Our Mission / VALUES を置くと、**理念 → 課題意識 → 事業のつくり → 働く人の共通点 → 数字**という流れになります。

- ミッション文は ABOUT の `h1`「PALを知る。」の直後が自然
- VALUE 01〜03 は、ABOUT の最後にある「活躍している人の、共通点。」の手前が候補
- HOMEで使っていた `.mission` / `.vals` / `.val` の部品をそのまま移設できる（CSSの追加なし）

### 案B：PEOPLE の `#look` に並べる

PEOPLE には既に「PALが大切にする3つの価値観」「6つの姿勢」「3つの力」があります。
ただし **VALUE 01〜03 とは別の内容**なので、同じページに2組の価値観が並ぶことになります。
並べるなら「会社としてのVALUE」と「働く人の姿勢」の違いが分かる見出しが必要です。

### 案C：理念専用の下層ページを新設

ミッション・スローガン・VALUE 01〜03 をまとめた `renewal/mission/` をつくる案。
情報の整理はいちばんきれいですが、ページが1枚増えます。
