## 1. ★ 公式カラーの確認結果

コーポレートサイト（www.pal-style.co.jp）の**描画済みスタイルを実測**し、
公式ロゴSVG（`company_logo.svg`）の塗り色も確認しました。

| 役割 | 実測値 | 出現状況（コーポレートTOP） |
|---|---|---|
| **PALレッド** | **`#CF131B`** | ロゴの赤／主CTAの塗り18件／文字84件／枠線85件 |
| ネイビー（濃） | `#1B1D31` | 文字506件・枠線416件 |
| ネイビー | `#262946` | 見出し179件 |
| グレー（補助） | `#797DAC` / `#6B6D81` | 本文・注記 |
| 枠線 | `#DAE1F2` | カード |
| 背景 | `#F2F3F6` / `#FFFFFF` | セクション |

### ⚠️ ご提示の仮カラーは公式ではありません

| ご提示 | 実際の公式 | 判定 |
|---|---|---|
| PAL RED `#D71920` | **`#CF131B`** | ✕ 不一致（ロゴSVGの実物も `#CF131B`） |
| DEEP NAVY `#202339` | `#262946` / `#1B1D31` | ✕ 不一致 |
| BLACK `#111318` | 使用なし（最も濃いのは `#1B1D31`） | ✕ |
| LIGHT GRAY `#F2F3F6` | `#F2F3F6` | ○ 一致 |
| WHITE `#FFFFFF` | `#FFFFFF` | ○ 一致 |

**「正式なブランドカラーを推測で設定しないでください」というご指示に従い、色の値は変更していません。**

### 採用サイトの現状

採用サイトの `:root` は `--red:#cf131b` / `--navy:#262946` / `--navy-d:#1b1d31` /
`--sub:#6b6d81` / `--muted:#797dac` / `--line:#dae1f2` / `--bg-soft:#f2f3f6`。
**すべてコーポレートと一致しています。** 色の値ではなく、**赤をどこに・どれだけ使うか**が違いです。

### 最大の差＝副CTA

| | コーポレート | 採用サイト（現行） |
|---|---|---|
| 主CTA | `#CF131B` 塗り・白文字・pill | 同じ |

## 3. コントラスト検証（WCAG AA）

| 色 | 白地 | 薄グレー地 | 判定 |
|---|---|---|---|
| `--text / --navy #262946` | 14.11 | 12.72 | OK |
| `--sub #6b6d81`（現行の本文） | 5.09 | 4.58 | OK（薄グレー上は余裕が少ない） |
| **`--muted #797dac`（現行の注記）** | **3.93** | **3.54** | **★通常文字AA未達** |
| `--red #cf131b` | 5.58 | 5.03 | OK |
| **A案・B案の本文 `#4f5168`** | **7.75** | **6.99** | OK |
| **A案・B案の注記 `#656a90`** | **5.23** | **4.71** | OK（AA通過に改善） |

| 組み合わせ | 比 | 判定 |
|---|---|---|
| 白地に赤文字 `#cf131b` | 5.58 | OK（副CTAの文字に使える） |
| 赤地に白文字 | 5.58 | OK |
| **濃紺地に赤文字 `#cf131b`** | **2.53** | **★NG。濃紺の上で赤文字は使わない** |
| **濃紺地に `#d94249`（赤を明るくした版）** | **3.81** | 大見出し（18.66px太字以上）ならOK |

→ **濃紺・動画の上でだけ使う赤 `--red-on-dark:#d94249` を新設**しました。
HEROの「自分の手で、」と、B案のJOIN PALラベルに使っています。

## 4. 共通のデザインルール（A案・B案の土台）

| 要素 | ルール |
|---|---|
| セクションラベル（`.slabel`） | PALレッド＋短い赤のルール（現行どおり） |
| H1・H2 | 濃紺 `#262946`。HEROなど濃紺背景の上では白 |
| H3・職種名 | 濃紺 |
| 本文 | `#4f5168`（現行 `#6b6d81` から濃く） |
| 注記 | `#656a90`（現行 `#797dac` はAA未達のため） |
| 主CTA | PALレッド塗り・白文字・pill |
| 副CTA | **白地・PALレッド文字・PALレッド枠・pill**（コーポレートと同じ） |
| 濃紺背景上の副CTA | 白枠・白文字（現行どおり。赤は使わない） |
| テキストリンク | 濃紺＋下線、ホバーで赤 |
| カード | 白背景・`#dae1f2` 枠。**ホバーで枠がPALレッドに** |
| バッジ | A案＝白枠／B案＝赤塗り |
| アコーディオン（FAQ） | 質問文は濃紺、開閉アイコンは赤、回答は `#4f5168` |
| フォーカス | `outline:3px solid var(--red); outline-offset:3px`（現行2pxから強化） |
| 強いセクション | HERO ／ JOIN PAL |
| 読ませるセクション | WORK職種カード／社員インタビュー／1日の流れ／FAQ／募集要項 → 白・薄グレー |

**CSS設計**：既存の `:root` 変数をそのまま使い、新しい色変数は `--red-on-dark` の**1つだけ**追加。
テーマは `body.th-a` / `body.th-b` のスコープ内で `--sub` / `--muted` を上書きする形にし、
個別セレクタへの色の直書きを増やしていません。

## 5. A案とB案の違い

| | A案 Brand Balanced | B案 Brand Impact |
|---|---|---|
| 共通 | 副CTAを赤枠に／本文・注記のコントラスト改善／HEROの「自分の手で、」を紫→赤グラデからPALレッド系単色へ／カードのホバーで赤 | 同左 |
| HEROのバッジ | 白枠のまま | **赤塗り・白文字** |
| 主CTA | 赤塗り＋control な影 | **赤塗り＋強い影、HEROでは一回り大きく（17px）** |
| セクション見出し | 下に**赤のルール 46×3px** | 下に**赤のルール 56×4px** |
| JOIN PAL | 現行（写真＋濃紺グラデ） | **濃紺ベタ＋上辺に赤の5pxライン、写真は opacity .14 のテクスチャ、ラベルは `#d94249`、CTAを大きく** |
| 読ませるセクション | 白・薄グレーのまま | 同左（**赤背景のセクションは増やしていません**） |
