## 確認が必要な3点

### 1. 休日はどちらが正式か

| 求人票の記載 | 示される月あたりの休日数 |
|---|---|
| 週休2日（シフト制） | 月8〜9日 |
| ※隔週2日休み（月6日〜） | 月6日〜 |
| 平均所定労働時間 168時間 ÷ 実働8時間 ＝ 月21日稼働（逆算） | 月9〜10日 |

→ **3つが互いに一致しない。** どれが実際の運用か。

### 2. 日勤・夜勤の時間帯と実働8時間の関係

求人票の記載：

- 日勤　8:00〜20:00／9:00〜21:00
- 夜勤　21:00〜翌9:00／24:00〜翌12:00／1:00〜13:00
- いずれも「実働8時間」

→ 拘束12時間に対し実働8時間。**休憩時間・待機時間の正式な扱いが記載されていない。**

### 3. 大型求人の車両トン数

| 出典 | 記載 |
|---|---|
| 求人票タイトル | ルート大型ドライバー**(8トン)** |
| 求人票 仕事内容 | **10トン**大型トラックを使用 |

→ どちらが正式か。両方を運用しているなら併記する。

1. `data/jobs-openings.json` の2件を直し、`status` を `"open"` に戻す。
2. 4tと大型を**同時に**更新する（同じ記載が両方にあるため）。
3. 4tの募集要項ページ（`renewal/jobs/dts/`）と大型（`tools/build_large_driver.py`）を復元・再生成する。
   旧ページは git 履歴から復元できる。
4. WORK・PEOPLE・FAQ の導線を戻す（`DRVHOLD v1` マーカーで囲んだ箇所）。
5. `bash tools/build_all.sh` で再生成し、JOBS一覧にドライバーカテゴリが戻ることを確認する。
