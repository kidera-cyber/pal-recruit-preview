## 2. 情報が足りず、拡充しきれなかった職種（2つ）

### Marketing / Content

リポジトリ内にあるのは、WORKパネルの3行（市場や顧客の変化を捉える／コンテンツの企画・制作／顧客との新しい接点づくり）と、
FAQ の1問のみ。**社員インタビュー・求人票・業務定義のいずれも存在しません。**

「この仕事で大切にしていること」は、根拠がないため**空のまま**にしています。

確認したいこと：担当媒体（Web・LP／コラム／SNS・動画／メルマガ／広告・分析のうちどれか）、
営業・事業部門との連携のしかた、募集職種としての担当範囲。
※ 承認済み求人票の「エンゲージメント・新規営業」には、休眠顧客向けメルマガ・LPの企画配信が
**営業側の業務**として書かれています。これをマーケティングの担当業務として書くことはできません。

### BizDev

リポジトリ内にあるのは、WORKパネルの2行と、FAQ の「募集職種はエンゲージメント・新規営業に含まれる」という記載のみ。

構想・検討・提案・実行のどの工程に関わるか。

## 3. 書かないように気をつけたこと

| 職種 | 避けた表現 |
|---|---|
| BPO | 全員が同じ順序・同じ責任範囲で担当するという書き方（注記で明示） |
| クレンリネス | 全員が複数拠点を管理する／すべての清掃計画を策定する（注記で明示）。募集状況は変更していない |
| System / Product | 開発者全員が現場に常駐する／設計から保守まで一人で担当する（「関わり方は案件によって異なります」に留めた） |
| DTS | 社員インタビュー（千葉営業所所長）の業務を、配送ドライバーの仕事として書くこと（注記で明示し、2つの役割を分けた） |
| Engagement / Sales | 提案から開発、現場導入まで営業が単独で担当するという書き方（注記で明示） |
| Corporate | 全担当者が総務・人事・経理・法務をすべて担当するという書き方（注記で明示） |
| 全職種 | 「幅広く活躍できます」「多様なスキルが身につきます」などの未確認表現、架空の成功事例、根拠のないキャリア保証 |

社員本人の言葉を使った箇所（BPO・System / Product・DTS・Corporate・Sales）は、
インタビュー本文の表現をそのまま、または語尾だけを整えて使用しています。
インタビューページ自体は1文字も変更していません。
